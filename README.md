# 📘 Lógica de Programação com Java

Este repositório contém minhas **resoluções dos exercícios** do curso **Lógica de Programação**, ministrado pelo **Prof. Nelio Alves**.

O curso equivale à disciplina introdutória de **Lógica de Programação** dos cursos superiores da área de Computação e utiliza a **linguagem Java**.

---

## 🎯 Objetivo do Repositório

- Praticar e consolidar os **fundamentos da lógica de programação**
- Desenvolver o **raciocínio lógico aplicado à resolução de problemas**
- Registrar minha evolução nos estudos
- Servir como material de revisão futura e portfólio no GitHub

---

## 📚 Conteúdos Abordados

### 🔹 Fundamentos
- Introdução à programação  
- Estrutura sequencial  
- Entrada de dados  
- Processamento de dados  
- Saída de dados  

### 🔹 Expressões
- Aritméticas  
- Comparativas  
- Lógicas  

### 🔹 Estruturas de Controle
- Estrutura condicional (`if / else`)
- Estruturas repetitivas:
  - `while`
  - `for`
  - `do-while`

### 🔹 Estruturas de Dados
- Vetores (arrays)
- Matrizes
